# Contributing

1. Read `AGENTS.md` and `docs/semantics.md`.
2. Edit only canonical inputs under `src/` or generator logic under `scripts/`.
3. Run `python3 scripts/generate.py`.
4. Run `python3 scripts/validate.py`.
5. Inspect all generated diffs, especially semantic mappings and contrast checks.

Changes to Flexoki accent values or Stargazing’s text semantics require explicit design approval. Do not weaken primary text by mapping body content to muted or faint roles.
